# Playbooks

## Google Ads

- Use search-intent messaging.
- Start from 3 to 8 keyword clusters, not hundreds of loose keywords.
- Match headline 1 to the primary offer or search theme.
- Description lines should reinforce outcome, proof, and CTA.
- Default objective: `Leads` if the user mentions calls, forms, demos, bookings, or enquiries.
- Default objective: `Website traffic` if the user asks for visits or clicks.
- Default objective: `Sales` if the user asks for purchases or revenue.

## Meta Ads

- Use simple awareness, consideration, or conversion framing.
- Creative should hook fast and keep the CTA obvious.
- Audience should combine one broad segment and one intent/proof angle.
- Stop before final publish unless the user explicitly asks to launch.

## LinkedIn

- Prefer authority, pain-point, and insight-led hooks.
- Target professionals, teams, founders, operators, or buyers explicitly when relevant.
- Avoid consumer-style hype language.

## Landing Page Review

Check these in order:

1. Headline says what the offer is.
2. Subheadline says who it is for or what outcome it drives.
3. CTA is visible without hunting.
4. Proof exists: testimonials, customers, numbers, screenshots, case studies.
5. Objections are addressed: pricing, trust, implementation, time-to-value.
6. Form or signup friction is not excessive.
